# ServiceNow ITSM Lab

Hands-on ServiceNow lab using a Personal Developer Instance (PDI) to 
practice Tier 1 helpdesk incident management workflows.

## What This Lab Covers
- Navigated the ServiceNow Incident List and ticket queue
- Created a new incident ticket with proper categorization and priority
- Assigned ticket to an agent and updated state to In Progress
- Documented troubleshooting steps using work notes
- Resolved ticket with resolution code and detailed resolution notes
- Understood SLA timers and how they drive response targets

## Environment
- Platform: ServiceNow (Australia release — latest)
- Instance type: Personal Developer Instance (PDI) — free tier
- Module: IT Service Management (ITSM) — Incident Management
- Role: ITIL User / System Administrator

## Scenario Practiced
Simulated a Tier 1 account lockout ticket — user unable to log into 
Windows workstation. Diagnosed via Active Directory, performed password 
reset and account unlock, confirmed resolution with user.
